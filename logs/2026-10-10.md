## What I learned
- A repo with the same name as your username shows its README at the top of your profile.
- Repo "About" (description, website, topics) is settings, not a commit — changing it doesn't redeploy anything.
- Adding a file like README.md *is* a commit, so Vercel redeploys connected projects.
- Big screenshots in a profile README look messy; a simple table with links reads better.
- skillicons.dev gives a neat row of tech icons from a single URL.
- GitHub achievements (Quickdraw, YOLO, Pull Shark…) come from real activity, not settings.
- The `<picture>` tag with `prefers-color-scheme` lets a README show different images in light/dark mode.
